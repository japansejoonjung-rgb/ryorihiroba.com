# レシピ広場

일본 사용자를 위한 레시피 커뮤니티 웹사이트 프론트엔드 MVP입니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 아래 주소를 여세요.

```txt
http://localhost:3000
```

## 기술 스택

- Next.js
- TypeScript
- Tailwind CSS
- React
- lucide-react
- Mock data 기반

## 주요 페이지

- `/` 홈
- `/recipes` 레시피 목록
- `/recipes/[id]` 레시피 상세
- `/categories` 카테고리
- `/ranking` 랭킹
- `/post` 레시피 등록
- `/login` 로그인 / 회원가입 UI
